# طقس الطيران — مساعد الطيارين لمطار البحرين الدولي (OBBI)

موقع ويب يعرض بيانات METAR وTAF الحية لمطار البحرين الدولي (ويدعم أي مطار آخر عبر رمز ICAO)، مع:

- شارة حالة الطيران الملوّنة (VFR / MVFR / IFR / LIFR)
- بوصلة رياح تفاعلية
- حاسبة الرياح الجانبية والأمامية لمدرجي OBBI (استناداً إلى اتجاه الرياح الحالي)
- تقرير METAR وTAF الخام + جدول تفاصيل مفكوك الترميز
- جدول زمني لتوقعات TAF مع تصنيف كل فترة
- فترة النهار (شروق/غروب/طول النهار) لمطار البحرين
- تحديث تلقائي كل 5 دقائق

## التشغيل

المصدر الرسمي لبيانات الطقس (`aviationweather.gov`) لا يسمح بطلبات المتصفح المباشرة (CORS)،
لذلك يتضمن المشروع خادم بايثون بسيط (بدون أي مكتبات خارجية) يخدم الملفات الثابتة
ويعمل كوسيط لجلب البيانات:

```bash
python server.py
```

ثم افتح المتصفح على: `http://localhost:8765`

يمكن تغيير المنفذ: `python server.py 9000`

## بنية المشروع

- `index.html` — الصفحة الرئيسية
- `style.css` — التنسيق
- `script.js` — منطق جلب البيانات، الحسابات، والعرض
- `server.py` — خادم الملفات الثابتة + وسيط CORS لـ aviationweather.gov

## ملاحظة مهمة

هذه الأداة لأغراض معلوماتية ومساعدة عامة فقط، ولا تُغني عن مصادر الطقس والنوتام
(NOTAM) الرسمية المعتمدة عند التخطيط الفعلي للرحلات.
